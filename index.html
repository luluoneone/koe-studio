はじめましょう

Koe Studio は、Google の Gemini API（Gemini TTS）で自分の声を登録して、演技を付けて読み上げるアプリです。

声の登録や音声の生成は、すべて Gemini API を通して行います。使うたびに、あなたの APIキーに Google の料金がかかります（使った分だけ）。

  1. Google AI Studio の APIキーの画面で「APIキーを作成」を押し、キーをコピーします。
  2. 下に貼り付けて「保存して始める」を押します。キーはこのパソコンの安全な保管場所（Mac はキーチェーン、Windows は資格情報マネージャー）に保存され、Google 以外には送られません。

ブラウザ版（予備）で開いています。サーバーを使わず、このブラウザから直接 Gemini API を呼びます。キーはこのタブの中だけで使い、「記憶する」を選んだときだけこのブラウザに保存します。音声は自動では保存されないので、「書き出し」で保存してください。

自分の声を登録するなら、AI Studio で「お支払い情報を設定」して有料枠にするのがおすすめです。無料枠では、送った録音や台詞が Google の改善に使われ、1日の回数にも上限があります。

読み上げ

台本を書いて、声と演技を選んで生成します。できたテイクは自動で保存されます。

生成のたびに Google の Gemini API を使うため、あなたの APIキーに料金がかかります（使った分だけ）。無料枠は1モデルにつき1日10回までです。

声を登録

自分の声を Gemini に登録します。3つの手順を順番に進めてください。

登録にも Gemini API を使います。

1

名前を付ける

あとで声を選ぶときに表示されます。英数字がおすすめです。

2

見本の録音を入れる

10〜30秒の、自然な話し声。台本を読むより、誰かに話しかけるように話すと抑揚が出ます。変換・編集していない元のファイル（QuickTime の m4a など）を使います。

3

同意文の録音を入れる

見本と同じ人・同じ部屋・同じマイクで、次の文を一字一句そのまま読みます。

私はこの音声の所有者であり、Googleがこの音声を使用して音声合成モデルを作成することを承認します。
登録の条件
  • 名前を入れた
  • 見本が10〜30秒
  • 同意文の録音を入れた

登録できるのは、同意文を自分で読んだ本人の声だけです。音声変換ソフトで作った声や、WAV に変換した録音は「合成音声」と判定されて登録できないことがあります。

声のライブラリ

登録した声です。保存期間は1年（1プロジェクト200個まで）。
