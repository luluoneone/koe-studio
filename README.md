# Koe Studio（声スタジオ）

[English](README.en.md) ・ 日本語

**Gemini TTS で、自分の声を登録して、演技を付けて読み上げる**ための、無料の小さなアプリです。
パソコンの中で動き、ブラウザの画面で操作します。Mac と Windows に対応しています。

- 自分の声を登録（Google の Voice Replication）
- 「明るく」「悲しく、声を震わせて」などの演技の指示と、間・ため息・笑いのタグを付けて読み上げ
- 作った音声は、自動で `出力` フォルダに WAV で保存
- Google の既製の声（30種類）も使える

> **このアプリは Google の Gemini API を使います。** 声の登録も音声の生成も、使うたびにあなたの APIキーに Google の料金がかかります（使った分だけ。無料枠は1モデルにつき1日10回まで）。無制限に無料で使えるアプリではありません。
>
> Google とは無関係の非公式ツールです。

## 必要なもの

- Mac（macOS）または Windows のパソコン
- Google アカウントと、Gemini の **APIキー**（無料で作れます）
- インターネット接続

Python などを自分で入れる必要はありません。最初の起動のときに、動かすのに必要な「uv」を入れるか聞かれます。

## はじめかた

1. このページの緑の「Code」→「Download ZIP」でダウンロードして、展開します。
2. 起動します。
   - **Mac**：`起動（Mac）.command` をダブルクリック
   - **Windows**：`起動（Windows）.bat` をダブルクリック
3. ブラウザで画面が開きます。[Google AI Studio の APIキーの画面](https://aistudio.google.com/apikey)でキーを作り、貼り付けて「保存して始める」を押します。
   キーはパソコンの安全な保管場所（Mac はキーチェーン、Windows は資格情報マネージャー）に保存されます。

止めるときは、起動したときに開いた黒いウィンドウで `Ctrl + C` を押します。

### 「開けません」と出たとき

- **Mac で「開発元を確認できません」**：`起動（Mac）.command` を右クリック →「開く」→「開く」。
  それでも開かないときは、システム設定 →「プライバシーとセキュリティ」の下にある「このまま開く」を押します。
- **Windows で「PC を保護しました」**：「詳細情報」→「実行」を押します。
- **Mac で「キーチェーンにアクセスしようとしています」**：保存したキーを読むための確認です。パスワードを入れて「常に許可」を押します。

## 自分の声を登録する

「声を登録」の画面で、次の2つの録音を入れます。どちらも**同じ人・同じ部屋・同じマイク**で録ってください。

1. **見本**：10〜30秒。台本を読むより、誰かに話しかけるように自然にしゃべると、抑揚のある声になります。
2. **同意文**：次の文を一字一句そのまま読みます。
   > 私はこの音声の所有者であり、Googleがこの音声を使用して音声合成モデルを作成することを承認します。

**録音は変換・編集しないで、そのまま使ってください。** Mac の QuickTime Player（ファイル → 新規オーディオ収録）で録った m4a はそのまま使えます。
WAV などに変換したものや、音声変換ソフトで作った声は、Google の安全確認で「合成音声」と判定されて登録できません。

登録した声は Google 側に1年間保存されます（1プロジェクト200個まで）。

## 料金と無料枠（2026年9月時点）

| | 無料枠 | 有料枠（使った分だけ） |
|---|---|---|
| 料金 | 0円 | Flash：音声100万トークンあたり $9、Flash-Lite：$6（2027年1月から約2倍） |
| 回数 | 1モデルにつき1日10回まで | 大幅に多い |
| 送った録音・台詞 | Google の改善に使われ、人が読む場合がある | 改善に使われない |

数秒の音声なら1本1円未満です。**自分の声を登録するなら、有料枠をおすすめします**（AI Studio で「お支払い情報を設定」）。
Google AI Pro などを契約している人は、毎月の Google Cloud クレジットを使える場合があります。
最新の料金は [Gemini API の料金ページ](https://ai.google.dev/gemini-api/docs/pricing)で確認してください。

EU・イギリス・スイスにいる人は、Google の規約により有料枠でしか使えません。

## 使ってはいけないこと

- 他人の声を、その人の同意なしに登録・使用すること
- なりすまし、詐欺、誤解を招く音声を作ること
- [Gemini API の利用規約](https://ai.google.dev/gemini-api/terms)と、Google の禁止事項に反する使い方

## よくあるトラブル

| 表示 | 対処 |
|---|---|
| APIキーが正しくありません | AI Studio でキーをコピーし直して、「設定」→「キーを入れ直す」 |
| 利用上限に達しました（429） | 無料枠の1日10回に達しました。翌日まで待つか、有料枠にします |
| 合成音声…と判定されました | 変換していない元の録音を使います |
| 安全確認に通りませんでした | 見本と同意文を、同じ人・同じ部屋・同じマイクで録り直します |
| 前払い残高とクレジットが0です（402） | AI Studio の Billing で残高を確認します |

エラーの全文は、起動したときの黒いウィンドウに表示されます。

## 仕組み（開発者向け）

- `app.py`：Python の小さなサーバー（`google-genai`、`keyring`）。`127.0.0.1` だけで待ち受け、起動ごとに作るトークンがないと操作できません。
- `index.html`：画面。外部のサイトやフォントを読み込みません。
- 使うモデル：`gemini-3.8-flash-tts`（演技重視）／`gemini-3.8-flash-lite-tts`（速い・安い）。
- 環境変数 `GEMINI_API_KEY` があれば、保存したキーより優先します。
- ターミナルから起動：`uv run app.py`（ブラウザを開かないときは `--no-browser`）。

Gemini の仕様や料金は変わることがあります。このツールは作った時点の仕様で動くもので、動作の保証はありません。
